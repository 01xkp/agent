# 创图工具箱使用指南

## 1. 怎么进入

启动项目后，AI Agent 工作台顶部中间有“创图工具箱”标签。

点击后进入工具箱；工具箱左侧可以返回 AI Agent 工作台。

工具箱免登录，图片优先在浏览器本地处理。

---

## 2. 智能证件照

### 基本步骤

1. 上传正面人像照片；
2. 选择证件照规格；
3. 选择白、蓝、红、蓝白渐变或自定义底色；
4. 点击生成证件照；
5. 检查像素和文件大小；
6. 下载高清 JPG。

如果没有先点“AI 智能抠图”，生成时也会自动抠图。

### 拍照建议

- 光线均匀；
- 人脸正对镜头；
- 不要让头发和衣服大面积超出画面；
- 背景和头发颜色尽量有区分；
- 原图越清晰，发丝边缘通常越好。

### 打印排版

生成证件照后，可以选择：

- 五寸相纸；
- 六寸相纸；
- A4 相纸。

系统会按照 300 DPI 自动计算行列和张数，加入裁切参考线，并导出打印版 JPG。

### 常见问题

**第一次抠图为什么慢？**

浏览器需要下载 AI 模型，后续通常会使用缓存。

**底色为什么必须先抠图？**

普通原图背景是不透明的，会盖住新底色。系统现在会自动使用透明人像结果换底。

---

## 3. 图片裁剪与尺寸修改

### 基本步骤

1. 一次选择一张或多张图片；
2. 选择自由裁剪或固定比例；
3. 拖动裁剪框；
4. 拖动右下角控制点调整大小；
5. 输入目标宽度和高度；
6. 预览并导出。

支持常用比例：

- 1:1；
- 16:9；
- 3:4；
- 4:3。

批量处理会对多张图片使用统一比例和目标尺寸。

---

## 4. 智能图片压缩

### 支持格式

- JPG / JPEG；
- PNG；
- WebP；
- GIF；
- SVG。

### 两种模式

**智能压缩**

适合大多数情况，优先在体积和清晰度之间取平衡。

**指定大小**

输入目标 KB，系统会自动尝试不同质量，尽量压到目标以内。

### 限制

- 最多 60 张；
- 单张最大 100MB；
- GIF 当前只提取首帧并转换为 WebP，不保留动画；
- SVG 会清理注释、空白和部分冗余文本。

页面提供对比滑块，可以观察压缩前后的画质。

---

## 5. Word 转 PPT

### 推荐格式

优先使用 `.docx`。

旧版 `.doc` 无法在当前浏览器方案中高质量解析，建议先用 Word 或 WPS：

```text
文件 → 另存为 → Word 文档（.docx）
```

### 基本步骤

1. 上传不超过 50MB 的 `.docx`；
2. 等待解析；
3. 查看幻灯片缩略图和预览；
4. 确认分页；
5. 下载 `.pptx`。

分页主要依据：

- 一级标题 H1；
- 二级标题 H2；
- 标题后的正文、列表、图片和表格文本。

### 转换边界

浏览器端转换会尽可能保留内容结构，但复杂 Word 排版、艺术字、宏、特殊图表和精确页眉页脚不一定能完全还原。

---

## 6. 隐私说明

- 图片处理优先在当前浏览器完成；
- 文件不会因为使用工具箱而自动写入聊天历史；
- 页面刷新或关闭后，对象 URL 会失效；
- 下载后的文件由用户自行保管；
- 使用真实第三方模型或未来外部服务前，应单独查看对应供应商的隐私政策。
